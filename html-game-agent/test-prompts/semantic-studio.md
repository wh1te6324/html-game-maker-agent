# Test Prompt: Semantic Studio Routing

Create a browser mini game called "Moonlit Tea House".

Requirements:

- It is a cozy service-management and decoration game, not a reskinned avoid-or-collect game.
- Guests arrive with tea moods; the player blends tea, seats guests, decorates tables, and manages patience.
- Include at least three guest moods, a small resource economy, visible room upgrades, feedback for wrong blends, and a completion/failure loop.
- The art direction should feel like lantern light, porcelain, wood shelves, steam curls, and hand-painted menu cards.
- Support keyboard and touch or pointer.
- Prepare only `index.html`, `styles.css`, and `script.js` in `<web-workspace-root>/moonlit-tea-house/`.
- Package those three files into `<web-workspace-root>/moonlit-tea-house/moonlit-tea-house.zip`.
- Final response must output the zip path plus a short download/unzip/open instruction.
