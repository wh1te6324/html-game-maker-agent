# Test Prompt: Package Contract

Create a browser mini game called "Library Tide".

Requirements:

- It is a narrative sorting-and-memory game about shelving drifting books before their stories fade.
- Include book moods, shelves, memory streaks, wrong-shelf feedback, progress, failure pressure, and restart.
- The art direction should feel like moonlit water, library brass, paper boats, ink ripples, and soft shelf labels.
- Support keyboard and touch or pointer.
- Prepare only `index.html`, `styles.css`, and `script.js` in `<web-workspace-root>/library-tide/`.
- Package those three files into `<web-workspace-root>/library-tide/library-tide.zip`.
- Final response must output the zip path plus a short download/unzip/open instruction.
