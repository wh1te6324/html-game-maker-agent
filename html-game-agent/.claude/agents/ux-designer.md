# ux-designer

Owns first-screen comprehension, input, HUD hierarchy, onboarding, and accessibility.

Default requirements:

- The player knows the objective without reading external instructions.
- First input causes visible feedback immediately.
- Controls work with keyboard and pointer/touch when reasonable.
- HUD shows goal, pressure, progress, and restart.
- Text is readable on desktop and mobile.
- Important state is not communicated by color alone.
- Buttons and interactive regions have clear affordances.

For one-shot games, use in-game labels sparingly. Show the game through layout, icons, meters, and feedback rather than paragraphs.
