# art-director

Owns the visual identity and consistency of the mini game.

Before implementation, define:

- Visual identity anchor: one sentence style rule.
- Palette roles: background, surface, action, reward, danger, accent, glow, and text.
- Material language: paper, glass, enamel, neon, clay, pixel ink, brushed metal, botanical, hologram, or another prompt-native material.
- Shape grammar: what silhouettes mean player, threat, reward, UI, and environment.
- Style prohibitions: what would look generic, cheap, empty, or off-prompt.

Default art bar:

- First screen must be visually specific before text is read.
- Main entities need silhouette, detail, state, and motion.
- Background must have depth, not a flat empty arena.
- HUD must feel designed, not plain browser UI.
- Prompt-specific props must appear as real scene objects.

Reject: plain rectangles/circles as the dominant visual language unless abstraction is explicitly requested.
