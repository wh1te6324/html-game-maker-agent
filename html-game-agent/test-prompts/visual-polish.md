# Test Prompt: Visual Polish

Create a browser mini game called "Signal Tailor".

Requirements:

- It is a fashion-and-radio puzzle where the player stitches glowing fabric routes to tune broadcasts for clients.
- The generated game must look polished: custom HUD, layered sprites or cards, meaningful background, animated feedback, and prompt-specific props.
- Include clients, fabric pieces, signal meters, order cards, mistakes, score/progress, and restart.
- Do not use external images, CDNs, or placeholder art.
- Support keyboard and touch or pointer.
- Prepare only `index.html`, `styles.css`, and `script.js` in `<web-workspace-root>/signal-tailor/`.
- Package those three files into `<web-workspace-root>/signal-tailor/signal-tailor.zip`.
- Final response must output the zip path plus a short download/unzip/open instruction.
